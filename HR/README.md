## Рекомендации по использованию

1. **Определите целевую вакансию** и выберите ближайший сценарий
2. **Скопируйте соответствующий файл** как основу резюме
3. **Адаптируйте формулировки** под конкретные требования вакансии
4. **Выберите сопроводительное письмо** из `Сопроводительные_письма.md` или составьте новое
