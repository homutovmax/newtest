# Документация репозитория newtest

Репозиторий объединяет несколько независимых проектов, ведущихся на одном ПК.
Каждый подпроект документирован отдельно:

| Документ | Подпроект |
|----------|-----------|
| [`SWAP.md`](SWAP.md) | SWAP — Equipment Request Portal (веб-портал заявок на оборудование) |
| [`HR.md`](HR.md) | HR — автоматизация карьеры: скрапинг вакансий, отчёты, письма |
| [`HA.md`](HA.md) | HA — диагностика и автоматизация Home Assistant |
| [Корневой README](../README.md) | Обзор всего репозитория и быстрый старт |

## Общие правила

- **Секреты не коммитятся.** Реальные ключи/пароли хранятся только локально;
  в репозитории — шаблоны (`.example`). См. `.gitignore`.
- **Секреты вычищены** из истории репозитория и заменены плейсхолдером `CHANGE_ME`
  (SSH-пароль, токен Home Assistant, SMTP-пароль, Telegram bot token). Перед запуском
  скриптов верните реальные значения в локальные копии файлов.
- **Перед деплоем HR** обязательно запускать `python run_tests.py` (exit code 0).
- **Ветка по умолчанию** — `master`.
